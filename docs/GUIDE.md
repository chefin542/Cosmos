# Cosmos 메모장으로 주보 쓰기 — AI 연결부터 주보 작성까지

회사에서 Claude(데스크톱 앱 또는 Claude Code)를 쓰고 있다면, 설치 후 "Claude Code 설정 가져오기"를 한 번 누르고 매주 "주보 작성하기"를 누르면 됩니다.

## 한눈에 보기

처음 한 번만 1~3단계로 연결해 두면, 그 뒤로는 매주 4·7단계(주보 작성하기 → 복사)만 하면 됩니다.

1. **설치** — 설치 파일을 받아 실행합니다.
2. **AI 연결** — 설정(⚙) → "Claude Code 설정 가져오기"를 누릅니다.
3. **모델 고르기** — 목록에서 모델을 고르고 "연결 테스트" → "저장"을 누릅니다.
4. **주보 작성** — 앱을 켜면 바로 보이는 주보 화면에서 "주보 작성하기"를 누릅니다.
5. **양식 바꾸기** (처음 한 번) — "양식 편집"에 회사 주보 양식을 붙여 넣습니다.
6. **보낼 내용 고치기** (필요할 때) — 이번 주만 기록을 더하거나 뺍니다.
7. **다듬어서 보내기** — 결과를 고친 뒤 "복사"해서 메일이나 사내 시스템에 붙여 넣습니다.

## 1. 설치

최신 설치 파일은 [Releases 페이지](https://github.com/chefin542/Cosmos/releases)에 있습니다. 맨 위 버전의 `cosmos-notes-…-win-x64.exe`를 받으세요.

1. 내려받은 exe 파일을 더블클릭합니다.
2. 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 개인이 만든 앱이라 서명 인증서가 없어서 나오는 안내입니다.
3. 설치가 끝나면 시작 메뉴에서 **Cosmos 메모장**을 엽니다.

새 버전은 기존 앱 위에 덮어서 설치하면 됩니다. 메모와 설정은 그대로 남습니다.

## 2. AI 연결

회사 PC에서 Claude 데스크톱 앱이나 Claude Code가 이미 동작한다면, 버튼 하나로 같은 연결 정보를 가져옵니다.

1. 오른쪽 위 **⚙ 설정**을 누릅니다. (주보 화면의 "AI 연결 설정 열기"도 같은 화면입니다.)
2. **AI 연결** 아래 파란 상자의 **Claude Code 설정 가져오기**를 누릅니다.
3. 서버 주소와 API 키를 찾아 채우고 저장합니다. 어디서 찾았는지 아래에 표시되고, 키는 끝 4자리만 보입니다.

찾는 곳은 Claude 데스크톱 앱의 회사 서버 설정, Claude Code 설정 파일(`~/.claude/settings.json`, 관리자 설정), 환경 변수입니다.

**키를 못 찾았다고 나오면** — 회사가 사내 로그인으로 키를 받게 해 둔 경우입니다. 받은 키를 **API 키** 칸에 붙여 넣고 **저장**하세요.

**아무것도 못 찾았다고 나오면** — 아래 칸을 직접 채웁니다. 서버 주소는 키를 준 담당자에게 물어보세요.

| 칸 | 넣을 값 |
| --- | --- |
| AI 요약 사용 | 체크 |
| API 형식 | Anthropic (Claude) 형식 |
| 서버 주소 | 회사 AI 서버 주소 (끝의 /v1은 있어도 자동으로 보정) |
| 인증 방식 | Authorization: Bearer (안 되면 x-api-key) |
| API 키 | 받은 키 |

API 키는 Windows 보안 저장소로 암호화해서 그 PC에만 저장됩니다.

## 3. 모델 고르기

서버 주소와 API 키만 있으면 모델 목록은 앱이 서버에서 받아옵니다. 모델 이름을 외울 필요가 없습니다.

1. 설정을 가져오거나 키를 저장하면 **모델** 칸 아래에 모델 이름 버튼들이 자동으로 나타납니다. 안 나타나면 **모델 목록 불러오기**를 누릅니다.
2. 쓸 모델 버튼을 누릅니다. 회사에서 Claude로 쓰던 모델을 고르면 됩니다.
3. **연결 테스트**를 누릅니다. 초록색 "연결 성공"이 나오면 됩니다.
4. **저장**을 누르고 오른쪽 위 ×로 설정을 닫으면 주보 화면으로 돌아갑니다.

여러 모델 중에서 고민되면 하나로 주보를 써 보고, 마음에 안 들면 설정에서 다른 모델로 바꿔 다시 써 보세요.

## 4. 주보 작성

앱을 켜면 오른쪽에 이번 주 주보 화면이 먼저 열립니다. 메모를 보다가도 왼쪽 위 보라색 **이번 주 주보** 버튼으로 돌아옵니다.

주보의 재료는 그 주(월~일)에 쓰거나 고친 메모와, 체크리스트에서 완료 표시한 할 일입니다. 평소에 업무를 메모하고 끝난 일을 체크해 두면 주보가 알차집니다.

1. **주보 작성하기**를 누릅니다. 서버에 따라 1~2분 걸릴 수 있습니다.
2. 결과가 화면에 나타납니다. 마음에 안 들면 **다시 작성**을 누릅니다.
3. 지난주 주보는 맨 위 주차 옆 **‹ ›** 화살표로 주를 옮겨서 씁니다.

화면 아래에는 새 메모·고친 메모·완료한 할 일 수와 요일별 기록이 나오므로, AI가 빠뜨린 것이 없는지 비교해 볼 수 있습니다.

## 5. 주보 양식 바꾸기

회사 주보 양식을 한 번 붙여 넣어 두면, 그다음부터 AI가 항상 그 모양대로 씁니다.

1. 주보 화면에서 **양식 편집**을 누릅니다.
2. **주보 양식** 칸의 내용을 지우고 회사 양식을 붙여 넣습니다. 괄호 안 설명은 AI가 실제 내용으로 바꿉니다.
3. **작성 지침** 칸에 문체·분량 같은 규칙을 한 줄에 하나씩 적습니다. (예: 항목마다 진행률(%)을 붙인다.)
4. **양식 저장**을 누르고 **다시 작성**합니다.

처음 기본 양식은 아래와 같습니다. 언제든 **기본 양식으로**를 눌러 되돌릴 수 있습니다.

```text
■ 금주 실적
1. (업무/프로젝트명)
   - (한 일과 결과)

■ 차주 계획
1. (업무/프로젝트명)
   - (할 일)

■ 이슈 및 협조 요청
- (없으면 "없음")
```

양식은 이 PC의 메모 데이터에 저장되므로 앱을 다시 켜도 유지됩니다. 연간 정리 양식은 "연간 정리" 탭에서 따로 바꿉니다.

## 6. 보낼 내용 고치기

메모에 없는 일을 더하거나 빼고 싶을 때, AI에게 보낼 기록을 이번 주에 한해 고칠 수 있습니다.

1. **보낼 내용 보기·고치기**를 누릅니다.
2. **보낼 기록** 칸을 직접 고칩니다. 예를 들어 끝에 `- 외부 미팅 1건`을 더하거나, 남기고 싶지 않은 줄을 지웁니다.
3. 아래에 "고친 내용으로 보냅니다"가 보이면 **주보 작성하기**를 누릅니다.

고친 기록은 앱을 끄면 사라지고, **원래대로**를 누르면 바로 되돌아갑니다. 매주 반복해서 고치는 내용이 있다면 5단계의 작성 지침에 넣는 편이 낫습니다.

"AI에게 주는 지시"를 펼치면 양식과 작성 지침이 어떻게 들어가는지 확인할 수 있습니다. 이 내용은 회사 AI 서버로만 전송됩니다.

## 7. 다듬어서 보내기

결과는 화면에서 바로 고칠 수 있고, 고친 내용 그대로 복사·저장됩니다.

1. 결과 글상자를 눌러 필요한 부분을 직접 고칩니다.
2. **복사**를 누르고 메일이나 사내 시스템에 붙여 넣습니다.
3. 기록으로 남기려면 맨 위 **메모로 저장**을 누릅니다. "주보 · 2026년 40주차" 같은 제목의 메모가 생기고, 주보 아래에 그 주 통계와 기록이 함께 적힙니다.

저장한 주보 메모는 다음 주보의 재료에서 자동으로 빠집니다.

## API 키가 바뀌었을 때

서버 주소는 그대로이므로 키만 바꾸면 됩니다. 모델 선택도 그대로 남습니다.

1. **⚙ 설정**을 엽니다.
2. **API 키** 칸("저장됨 — 바꾸려면 새 키를 입력")에 새 키를 붙여 넣습니다.
3. **연결 테스트**로 확인하고 **저장**을 누릅니다.

Claude 데스크톱 앱에도 새 키를 넣었다면, 직접 붙여 넣는 대신 **Claude Code 설정 가져오기**를 다시 눌러도 됩니다.

## 문제 해결

연결 테스트나 주보 작성이 실패하면 빨간 상자에 원인과 해야 할 일이 나옵니다. 자주 나오는 경우는 아래와 같습니다.

| 화면에 나오는 말 | 해볼 일 |
| --- | --- |
| 인증에 실패했습니다 (HTTP 401) | 키를 다시 붙여 넣기. 그래도 안 되면 인증 방식을 Bearer ↔ x-api-key로 바꿔 테스트 |
| 주소나 모델을 찾을 수 없습니다 (HTTP 404) | 모델 목록 불러오기로 모델을 다시 고르기, 서버 주소 확인 |
| 서버에 연결하지 못했습니다 | 사내망·VPN 연결 확인. 회사 밖에서는 사내 서버에 닿지 않습니다 |
| 보낼 내용이 모델이 한 번에 받을 수 있는 양보다 많습니다 | 설정 → 고급 설정 → "최대 전송 글자 수"를 줄이기 (예: 10000) |
| 시간 안에 응답이 없어 중단했습니다 | 설정 → 고급 설정 → "시간 제한(초)"을 늘리기 |
| 답변이 최대 출력 토큰에서 잘렸습니다 | 설정 → 고급 설정 → "최대 출력 토큰"을 늘리기 |
| 주보가 양식과 다르게 나옴 | 양식 편집의 작성 지침에 규칙을 더하거나 다른 모델로 바꿔 보기 |

그래도 안 되면 설정 맨 아래 **진단 정보 복사**를 눌러 담당자나 Claude에게 보여 주세요. 진단 정보에는 API 키가 들어가지 않습니다.
